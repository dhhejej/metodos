Análisis de regresión múltiple

El modelo de regresión múltiple es una extensión práctica del modelo que vimos en la clase anterior. Nos permite construir un modelo con varias variables independientes. 

Y = b0 ​+ b1​X1 ​+ b2​X2 ​+ ... + bk​Xk

Ver ejercicio de la página 14 y 15, análisis de regresión múltiple:

Considere el caso de Jenny Wilson Realty, una compañía de bienes raíces en Montgomery, Ala- bama. Jenny Wilson, dueña y corredora de esta compañía, quiere desarrollar un modelo para determi- nar los precios listados sugeridos para las casas con base en el tamaño y la antigüedad de estas. Selecciona una muestra de casas que se hayan vendido recientemente en un área específica y registra el precio de venta, los pies cuadrados de construcción y la antigüedad de cada una; además, regis- tra la condición (buena, excelente o nueva) como se indica en la tabla:

Resolver el ejercicio en R

Paso 1: Crear el conjunto de datos

precio <- c(95000, 119000, 124800, 135000, 142800, 145000, 159000, 
            165000, 182000, 183000, 200000, 211000, 215000, 219000)

pies_cuadrados <- c(1926, 2069, 1720, 1396, 1706, 1847, 1950, 
                    2323, 2285, 3752, 2300, 2525, 3800, 1740)

antiguedad <- c(30, 40, 30, 15, 32, 38, 27, 30, 26, 35, 18, 17, 40, 12)

Paso 2: Crear el Data Frame

datos_casas <- data.frame(precio, pies_cuadrados, antiguedad)

Paso 3: Ajustar el modelo de regresión múltiple usando lm()

Sintaxis: variable-dependiente ~ variable-independiente1 + variable-independiente2 

modelo_multi <- lm(precio ~ pies_cuadrados + antiguedad, data = datos_casas)

Paso 4: Ver los resultados principales del modelo

print(modelo_multi)

Paso 5: Obtener un resumen estadístico detallado

summary(modelo_multi)

Paso 6: Calcular el precio pronosticado

Crear un nuevo data frame con los datos de una casa a pronosticar Ejemplo: Una casa de 2,000 pies cuadrados y 10 años de antigüedad 

nueva_casa <- data.frame(pies_cuadrados = 2000, antiguedad = 10)

Calcular el precio pronosticado 

precio_estimado <- predict(modelo_multi, newdata = nueva_casa)
